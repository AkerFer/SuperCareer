# Football Legacy 2.3

- `Football-Legacy-2.3.apk` — тестовая устанавливаемая debug-сборка, Android 7.0+ с обновлённым Android System WebView.
- `Football-Legacy-2.3.zip` — тот же APK в архиве, если загрузка APK внутри чата блокируется. Откройте ссылку во внешнем Chrome, распакуйте через «Файлы» и установите APK.
- Package ID: `com.footballlegacy.career`, versionName `2.3`, versionCode `5`.

Устанавливайте поверх предоставленной 2.2, **не удаляя приложение**, чтобы сохранить карьеру. Подпись прежняя. Перед обновлением можно экспортировать JSON в настройках. На физическом Android-устройстве сборка не проверялась.

Контрольные суммы — в `SHA256SUMS`, пути указаны от корня репозитория. Предыдущие файлы 2.2 сохранены, чтобы старые ссылки продолжали работать.

Пересборка: `npm ci`, `npm run android:apk` из корня при наличии JDK 21 и Android SDK 36. Возможности и ограничения — в [описании сайта](../../website/README.md) и [источниках данных](../../website/DATA_SOURCES.md).
