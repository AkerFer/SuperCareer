# Football Legacy 2.2

`Football-Legacy-2.2.apk` — устанавливаемая тестовая debug-сборка, Android 7.0+ с обновлённым Android System WebView. Package ID: `com.footballlegacy.career`, versionName `2.2`, versionCode `4`.

Установите поверх предыдущего предоставленного APK, **не удаляя приложение**, чтобы сохранить локальную карьеру. Подпись совпадает с APK 0.2.1. Для резервной копии используйте экспорт JSON в настройках. На физическом Android-устройстве эта сборка не проверялась.

Контрольная сумма — в `SHA256SUMS` (путь в файле указан от корня репозитория). Пересборка: `npm ci`, затем `npm run android:apk` из корня, при наличии JDK 21 и Android SDK 36.

Игровые изменения и ограничения источников описаны в `website/README.md` и `website/DATA_SOURCES.md`. Фотографии футболистов временно отключены; эмблемы клубов включены.
