# Источники и ограничения данных

## Футболисты

- Premier League: исторический `players_raw.csv` и `teams.csv` сезона **2024/25** из [vaastav/Fantasy-Premier-League](https://github.com/vaastav/Fantasy-Premier-League/tree/master/data/2024-25). По 22 игрока клуба выбирались по игровым минутам и группам позиций. Точные позиции внутри широких категорий FPL — игровая интерпретация. Используются реальные имена и даты рождения, когда доступны.
- Остальные четыре лиги: редакционный исторический список реальных футболистов в `src/data/editorial-rosters.txt`. Он объединяет разные даты сезона 2024/25, не является официальной актуальной заявкой. Дополнения и удаления после генерации отражены в `src/data/rosters.json`.
- Итого в начальной базе 1529 реальных имён. Остальные места — явно отмеченные сгенерированные футболисты академии. Новые сезоны создают вымышленных выпускников. Для ведущих футболистов дополнительно заданы известные годы рождения в src/data/birth-years.json. При неизвестном возрасте используется помеченная оценка 26 лет, исключённая из молодёжных наград. Рейтинги, потенциал, стоимость, зарплата, контракт, а также недостающий возраст и национальность не являются официальными показателями. Неизвестная национальность помечена «Не указана».
- Редактирование базы: JSON в `src/data/rosters.json`; повторная генерация — `scripts/build-rosters.py`. После изменения пересоберите приложение.

## Эмблемы и фотографии

- 96 эмблем клубов сезона 2024/25 из публичного [luukhopman/football-logos](https://github.com/luukhopman/football-logos). Точный исходный путь каждой эмблемы сохранён в `src/data/logo-sources.json`. Картинки упакованы в `public/media/clubs`, работают офлайн. Названия и эмблемы принадлежат соответствующим правообладателям; официальное партнёрство не подразумевается.
- Фотографии игроков Premier League подключены внешними ссылками по идентификаторам публичной FPL-базы: `https://resources.premierleague.com/premierleague/photos/players/250x250/p<ID>.png`. Они требуют Интернета и доступности сервиса. Это не пакет локальных фотографий для всех игроков. При ошибке показываются инициалы. Лицензия базы фактов не распространяется автоматически на фотографии и эмблемы.
- В карточке любого футболиста можно назначить собственную HTTPS-ссылку на фото. Ссылка сохраняется в карьере и экспортируется вместе с JSON.
- Для расширения данных найден CC0-набор [dcaribou/transfermarkt-datasets](https://github.com/dcaribou/transfermarkt-datasets). Его README сообщает об остановке обновлений в июле 2026 года. Файл базы и Wikimedia Commons заблокированы текущей сетевой политикой среды; необходимые домены сохранены в черновике настроек, но без применения пользователем недоступны. Неполученные составы/фотографии не включены в сборку.

## Лига чемпионов

Реализована игровая адаптация формата с 36 участниками: 8 уникальных соперников, общий зачёт, топ-8 в 1/8, 9–24 — двухматчевые стыки, 1/8, 1/4, 1/2 в два матча, один финал. При равенстве суммы — серия пенальти; правило выездного гола и дополнительное время не применяются. Упрощены жеребьёвка, распределение домашних матчей и квоты: 8 клубов Англии и по 7 остальных четырёх лиг. Первый сезон — посев по игровой силе, затем — реальные таблицы **внутри карьеры**. Официальный состав участников и все квалификационные пути UEFA не воспроизводятся.

## Награды

Все награды рассчитываются по статистике симуляции. Формула показана на церемонии. Средняя оценка — вычисляемая игровая оценка матча, не внешние рейтинги. При точном равенстве индекса используется стабильный ID игрока/клуба, а не случайный выбор. Золотая бутса считает только голы национальных лиг с коэффициентом 2. Все церемонии можно повторить без повторной выдачи наград. Ballon d’Or хранит топ-30; остальные награды — топ-5 и/или сборную сезона. При отсутствии сыгравших претендентов (например, молодого вратаря) соответствующая награда не создаётся.

## Дополнение к веб-версии: амплуа и портреты

`src/player-roles.ts` — редакционная таблица основных/дополнительных реальных амплуа с точными полными именами и явными псевдонимами. Сопоставление по окончанию фамилии удалено: Amadou Onana не превращается во вратаря André Onana, Lisandro Martínez не получает роль Emiliano Martínez. Для неподтверждённых точных ролей FPL используется исходная широкая категория (`src/data/fpl-role-groups.json`, те же данные 2024/25): GK/DF/MF/FW. Это не выдаётся за официальную многофункциональность каждого игрока. Вратари не получают вымышленные дополнительные полевые позиции.

`src/photo-service.ts` обращается к публичным API `www.wikidata.org` и `commons.wikimedia.org` прямо из браузера пользователя. При единственном точном совпадении имени с описанием football/soccer берётся изображение P18, а на Commons запрашиваются URL, автор и лицензия. При неоднозначности поиск прекращается. Используются только HTTPS-изображения `upload.wikimedia.org` с атрибуцией. Отсутствующие фотографии не заменяются сгенерированными лицами. Текущий профиль Wikidata не означает, что сам снимок сделан в текущем сезоне.

Проверка протокола API проведена на контролируемых ответах. Текущая облачная сетевая политика не разрешает прямые запросы к этим источникам, поэтому загрузка живых портретов в ней не подтверждена. На компьютере пользователя доступность зависит от его сети. Назначенная вручную HTTPS-ссылка в карточке игрока остаётся доступной.

## FC 26: подтверждённый снимок OVR и позиций

`src/data/fc26-ratings.json` — извлечение числовых рейтингов для 1337 однозначных совпадений имён из [EAFC26-DataHub/data/players.csv](https://github.com/ismailoksuz/EAFC26-DataHub/blob/main/data/players.csv). Указанный репозиторием первоисточник: [FC 26 Player Data / rovnez](https://www.kaggle.com/datasets/rovnez/fc-26-fifa-26-player-data). Снимок `fifa_version=26`, `fifa_update=4`, `fifa_update_date=2025-09-19`; SHA-256 исходного CSV: `cb46c2a57eff44f3c7e098a8a7e807113d0524fee3c1737c39262dcfd4e9824d`. Это сторонний архив данных игры, не прямая синхронизация с EA и не обновление ноября 2026 года.

Сопоставляются полное/краткое точное имя либо все токены многословного имени с единственным полным именем; неоднозначные совпадения пропущены. Фотографии и денежные значения EA из этого набора не копировались и не выдаются за Transfermarkt. Для основной позиции используется Overall карточки; для другой позиции — архивная позиционная оценка (сумма базового показателя и указанного бонуса, максимум 99). При развитии в карьере применяется разница текущего OVR и исходного. Это игровая адаптация позиционных оценок. Проверенные редакционные дополнительные амплуа сохраняются вместе с карточными. После развития следующего сезона текущий OVR уже является результатом симуляции и не помечается официальным FC.

## Импорт Transfermarkt и EA FC

Настройки → импорт базы принимает CSV и gzip до 32 МБ, с датой снимка и ссылкой на источник. Transfermarkt: `name`, `market_value_in_eur`, `image_url`; EA FC: `long_name` (или `name`), `overall`, `player_positions`. Имена нормализуются по диакритике, регистру и пунктуации, затем требуется единственное точное совпадение. Неизвестные/неоднозначные имена и повторные записи пропускаются; при отсутствии обновлений карьера не меняется. Цена должна быть текущей стоимостью в евро, не `highest_market_value_in_eur`. Ссылки на изображения сохраняются как внешние, сами фотографии не упаковываются. Права и доступность изображения зависят от источника.

Для неполученных данных Transfermarkt цены остаются моделируемыми. В следующем сезоне стоимость рассчитывается движком, и метка внешней оценки снимается. Дата происхождения OVR и цены отображается в карточке футболиста.

Вместо фотографий используются инициалы; изображения не загружаются даже при наличии старой ссылки в сохранении. Эмблемы клубов сохранены. Отдельная база фотографий будет добавлена позднее.
