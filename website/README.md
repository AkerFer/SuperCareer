# Football Legacy 2.3 — сайт

React + TypeScript, браузерная игра без регистрации. Android использует тот же игровой код из этой папки.

Из корня репозитория:

```sh
npm ci
npm run dev -- --port 5173
```

Откройте `http://localhost:5173`. Production: `npm run build`; результат — `website/dist/`. Для просмотра сборки: `npm run preview -- --port 4173`.

## Что работает в 2.3

- Девять лиг, 180 клубов и 3960 мест в начальных составах. Добавлены MLS, Saudi Pro League, Primeira Liga и Süper Lig. Реальные имена из архивных источников; недостающие места занимают обозначенные игроки академии.
- Новая жеребьёвка календаря каждый сезон с сохранением домашнего/выездного баланса. MLS: две фиксированные конференции по 15 клубов, 28 матчей внутри конференции и 6 межконференционных, итого 34 матча на клуб. Упрощённый игровой календарь, а не официальное расписание.
- ЛЧ, ЛЕ, ЛК, Суперкубок UEFA и 21 национальный кубковый розыгрыш. На телефоне сетка переключается по стадиям, на компьютере показываются колонки. Полный список матчей можно раскрыть отдельно.
- Национальные кубки: FA Cup, EFL Cup, Community Shield; Copa del Rey, Supercopa; Coppa Italia, Supercoppa; DFB-Pokal, DFL-Supercup; Coupe de France, Trophée des Champions; US Open Cup, MLS Cup, Canadian Championship; King Cup, Saudi Super Cup; Taça de Portugal, Taça da Liga, Supertaça; Türkiye Kupası, Turkish Super Cup.
- Суперкубки Испании, Италии, Саудовской Аравии и Турции — четыре клуба, полуфиналы и финал. Другие суперкубки — один финал. Следующий розыгрыш использует чемпионов/финалистов предыдущего сезона; первый — игровой посев.
- Кубки адаптированы к имеющимся высшим дивизионам: один матч, при ничьей пенальти, при необходимости пропуск первого раунда. Нижние лиги не симулируются. Leagues Cup и Campeones Cup не включены: Liga MX отсутствует. В Canadian Championship участвуют только три доступных канадских клуба MLS.
- Квоты ЛЧ в расширенном мире: Англия 7; Испания и Италия по 6; Германия и Франция по 5; Португалия 4; Турция 3. MLS и Saudi Pro League не участвуют в UEFA. Общий этап ЛЧ — 36 участников; ЛЕ и ЛК сохраняют адаптированный групповой формат.
- С поля по нажатию открывается досье игрока: текущие показатели, история клубов и сезонов внутри карьеры, сборная, награды, переходы. Режим «Менять состав» сохраняет перестановки нажатием; перетаскивание мышью и ручкой ⠿ работает в обоих режимах. При живом матче замены разрешены только на паузе/в перерыве.
- История клубной статистики заполняется матчами, показатели сборной хранятся отдельно и не попадают в таблицы клубов. Данных о реальной карьере до начала игры нет; старые недетализированные показатели не выдумываются.
- Календарь карьеры и список матчей включают клубные кубки и UEFA. SVG-значки различают соревнования; цвета результата с точки зрения вашего клуба: победа зелёная, ничья жёлтая, поражение красное.
- Переговоры с встречной ценой, согласованной зарплатой, проверкой бюджета и анимацией подписания. Ошибки видны поверх карточки. Окна — январь, июль–август; свободные агенты круглый год. Аренды до 30 июня с возвратом владельцу.
- Стоимость — калиброванная игровая модель: возраст, OVR, потенциал, позиция. Высокий рейтинг молодого игрока существенно дороже рейтинга возрастного ветерана. Это не котировки Transfermarkt. Интерфейс импорта Transfermarkt удалён; JSON для резервного копирования карьеры остаётся.
- Золотой мяч учитывает вклад с поправкой на силу лиги и игровое время, трофеи клубов и сборных, ЛЧ, сборную и fair play. За ЧМ добавляется 45 баллов, за EURO/Copa — 25, только участвовавшим игрокам. Это детерминированная игровая адаптация критериев France Football, не официальное голосование. Золотая бутса исключает MLS/Саудовскую Аравию; топ-5 коэффициент 2, Португалия и Турция 1,5. Награды лиг разделены по лигам.
- Темы: голубая, белая, чёрная, розовая. Выбор сохраняется на устройстве. Анимация названия при запуске, SVG-навигация и более плавная тактическая доска.
- Экран матча сохраняет высоту: в ленте только голы; VAR, карточки и травмы показываются временными оверлеями. Все события остаются в данных и подробностях матча. 90 минут — около 10 секунд активной симуляции, без учёта ручного перерыва и VAR.
- Автосохранение после действий без уведомлений об успешной записи; ошибки сохранения остаются видимыми. Три слота, сжатый формат FL2, журнал текущего матча, экспорт/импорт JSON и удаление текущей карьеры с подтверждением.
- Фотографии игроков по-прежнему отключены. Старые эмблемы клубов работают офлайн; для новых клубов без изображения используются инициалы.

## Совместимость

Сохранения 2.2 читаются. Новые лиги добавляются, их прошедшие туры моделируются до текущей игровой даты. Прежние результаты и купленные игроки сохраняются. История статистики по клубам накапливается с обновления; старый общий итог остаётся доступным. Для активного живого матча расширение откладывается до его завершения. Новые квоты UEFA применяются со следующего отбора.

## Проверка

`npm test` из корня проверяет движок, включая 30 сезонов, кубки, трансферы, аренды, дисциплину, позиции, старые сохранения и разделение статистики сборных. Полная проверка может занять несколько минут.

При запущенном Vite:

```sh
npm run test:browser --workspace @football-legacy/website
npm run test:website-update --workspace @football-legacy/website
npm run test:competitions --workspace @football-legacy/website
npm run test:update23 --workspace @football-legacy/website
```

Нужен Chromium: `CHROMIUM_PATH`, по умолчанию `/usr/bin/chromium`; адрес сайта задаётся через `BASE_URL`. Скриншоты — в `artifacts/` корня, они не входят в git.

Основные модули: `engine.ts`, `career.ts`, `live.ts`, `domestic.ts`, `continental.ts`, `international.ts`, `market.ts`, `pricing.ts`, `storage.ts`. Источники и ограничения — в [DATA_SOURCES.md](DATA_SOURCES.md).
