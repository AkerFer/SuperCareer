# Football Legacy — сайт

Это основное приложение игры: весь интерфейс React, футбольная симуляция, данные, составы, трансферы, ЛЧ, сезонные награды, досье тренера и сохранения находятся здесь.

Из корня репозитория:

```sh
npm ci
npm run dev -- --port 5173
npm run build
```

Или после общей установки из этой папки: `npm run dev`, `npm run build`, `npm test`.

`dist/` содержит готовый статический сайт. Публикуйте содержимое папки в корне сайта на статическом HTTPS-хостинге. Локальная проверка production: `npm run preview -- --port 4173`. Ссылка на публичный хостинг автоматически не создаётся.

## Файлы для дальнейшей разработки

- `src/main.tsx` — навигация и экраны.
- `src/engine.ts`, `src/career.ts`, `src/live.ts` — движок чемпионатов, ЛЧ, наград и живых матчей.
- `src/LineupView.tsx`, `src/lineup.ts`, `src/tactics.ts` — поле, состав, позиции и замены.
- `src/AwardsView.tsx`, `src/CoachView.tsx` — церемонии и досье тренера.
- `src/storage.ts` — три слота, сжатые сохранения FL2 и журнал текущего матча; читает старый JSON-формат.
- `src/export.ts` — загрузка JSON в браузере и интерфейс подключения экспорта для другой платформы.
- `src/data/`, `public/media/` — игровые данные и локальные изображения.

Веб-часть не импортирует Capacitor и не требует Java или Android SDK. Android-оболочка использует эти исходники, подключая свой адаптер экспорта. Изменения логики достаточно сделать один раз здесь.

## Проверка

`npm test` проверяет игровой движок, включая карьеру на 30 сезонов. Для браузерного теста сначала запустите Vite на 5173, затем `npm run test:browser`. Нужен Chromium (`CHROMIUM_PATH`, по умолчанию `/usr/bin/chromium`); адрес можно переопределить переменной `BASE_URL`. Скриншоты сохраняются в `../artifacts/`. Сценарий проверяет состав на поле, расстановки, матч с перерывом, замену и восстановление, трансфер, ЛЧ, награды, тренера, новый сезон и скачивание JSON.

Текущая версия использует историческую стартовую базу 2024/25. Источники и ограничения — в [DATA_SOURCES.md](DATA_SOURCES.md). Перенос в отдельную папку не подменяет базу актуальными составами 2026/27. Архив подробных заметок предыдущей структуры: [docs/legacy-v0.2.md](docs/legacy-v0.2.md).

## Веб-обновление: управление карьерой и VAR

Предыдущее обновление выполнялось только в `website/`. В выпуске 2.2 все накопленные изменения включены и в Android APK.

- **Выбор клуба:** карточки клубов с эмблемами, отдельные вкладки пяти лиг, цвета чемпионатов и поиск. Выбранный клуб виден под сеткой.
- **Два режима при создании:** «Календарная карьера» позволяет выбирать дату, проматывать день, неделю или сезон; «Каждый матч» открывает отдельный центр матча и не даёт автоматически пропускать игры своего клуба. Матчи ЛЧ также требуют участия в этом режиме. Для старых сохранений сохраняется календарный режим.
- **Карьера:** отдельная вкладка с игровым календарём, результатами и ближайшим соперником. Расписание игровое — один национальный тур в неделю, ЛЧ между турами; это не официальный календарь.
- **Центр матча:** текстовая симуляция, перерыв, ручная пауза, замены и заметный баннер забившего игрока. Уход с вкладки приостанавливает матч. Состояние, включая решение текущего VAR, сохраняется.
- **Перетаскивание:** мышью можно тянуть карточку запасного на позицию, игрока на поле на другую позицию или на запасного. На сенсорном экране используйте ручку ⠿; она не мешает прокрутке списка. Касания и выбор игрока остаются доступны. Все способы проходят через одни и те же проверки замен.
- **Позиции:** основная позиция отделена от дополнительных амплуа. Реальные профили заданы точными именами в `src/player-roles.ts`, без подстановок по фамилии. Автовыбор и сила игрока учитывают дополнительные позиции; перестановка на поле не меняет амплуа футболиста. Если источник FPL сообщает только группу, показываются DF/MF/FW вместо выдуманного точного амплуа.
- **VAR в интерактивной игре:** спорный гол проверяется до изменения счёта и статистики. Возможно подтверждение или отмена, а для прямой красной — подтверждение, отмена или жёлтая. Сохранение не меняет заранее принятое симулятором решение. Это игровая вероятностная модель, без 3D-анализа эпизода.
- **Карточки:** две жёлтые в матче дают удаление; удалённый больше не участвует в симуляции и не заменяется. Игровой регламент дисквалификаций: накопление пяти жёлтых — один матч, вторая жёлтая — один матч, прямая красная — три. Учёт лиги и ЛЧ раздельный. Дисквалификация отбывается в следующем матче соответствующего турнира.
- **Портреты:** ссылка на фото используется первой (для FPL проверяется современный CDN и прежняя ссылка). При отсутствии изображения видимый реальный игрок ищется по однозначному футбольному профилю Wikidata, затем берётся P18 с Commons. Автор и лицензия сохраняются в настройках → «Фотографии футболистов». Запросы ограничены двумя одновременно, метаданные кэшируются. Для загрузки нужен Интернет и доступ к Wikimedia; при отсутствии однозначного профиля/изображения остаются инициалы. Дата снимка не гарантируется текущим сезоном. Имена с неоднозначными совпадениями автоматически не подменяются чужими лицами.

Дополнительная браузерная проверка:

```sh
# Из корня, с уже запущенным Vite на 5173:
npm run test:website-update --workspace @football-legacy/website
```

Проверяются native drag-and-drop, настоящий touch-ввод Chromium, выбор лиги/клуба и обоих режимов, VAR, голевой баннер, переход в центр матча со страницы ЛЧ. Протокол фотографий и атрибуции проверяется на контролируемых ответах API; доступ к живому Wikimedia в облачной среде этим тестом не утверждается. `npm test` включает 18 проверок движка и карьеру на 30 сезонов.

Для установки только сайта из корня, без Android-пакетов:

```sh
npm ci --workspace @football-legacy/website --include-workspace-root=false
npm run dev
```

## Еврокубки, сборные и трансферы — обновление сайта

Во вкладке «Турниры» теперь отдельные разделы ЛЧ, ЛЕ, ЛК, Суперкубка, сборных и национальных лиг. Национальные таблицы сохранены. У кубков есть анимированная горизонтальная сетка; календарь карьеры и список матчей показывают все клубные соревнования. Победа зелёная, ничья жёлтая, поражение красное. Награды лиг выбираются по чемпионату, а выбранная церемония не переходит в награды других лиг. На полке тренера — отдельные SVG-кубки с повторяемым открытием.

ЛЕ: 32 участника, 8 групп, 6 туров, топ-2 в 1/8. ЛК: 24 участника, 6 групп, топ-2 и четыре лучших третьих места в 1/8. Плей-офф двухматчевый, финал один. Это **упрощённые игровые форматы**, не официальный новый общий этап UEFA. Клубы отбираются из пяти доступных лиг, без пересечения с ЛЧ; Суперкубок — победители предыдущих ЛЧ и ЛЕ. Для первого Суперкубка нужно закончить сезон.

ЧМ проходит летом 2026, 2030 и далее; EURO и Copa — летом 2028, 2032 и далее. Форматы: 48, 24 и 16 сборных соответственно, группы и одиночный плей-офф. Сборные имеют отдельную игровую модель силы и упрощённую квалификацию; это не официальные заявки и не управление национальной командой. Статистика клубов не смешивается с результатами сборных.

Окна по игровым датам: январь и июль–август (общий упрощённый календарь для пяти лиг). Вне окна доступны свободные агенты. В карточке игрока можно обсудить цену, получить встречное предложение, согласовать контракт и посмотреть анимацию подписания. Аренда до 30 июня стоит 5% стоимости, зарплату полностью платит принимающий клуб; по завершении игрок возвращается владельцу. Арендованного игрока нельзя продать или продлить как собственного.

Травмы учитывают нагрузку: ушибы, растяжения, повреждения мышц, голеностоп, редкие разрывы крестообразной связки. Сроки 3–300 дней. Срок тяжёлой травмы сохраняется при переходе сезона; это вероятностная игровая модель, не медицинский прогноз. В составе показывается OVR для выбранной позиции. Для подтверждённых игроков используются данные FC 26, для остальных — позиционный коэффициент.

В настройках доступен импорт `CSV`/`CSV.GZ` Transfermarkt и EA FC. Укажите дату и ссылку на источник. Неоднозначные имена пропускаются, текущие характеристики сохраняются с происхождением. До импорта стоимость остаётся игровой оценкой. Сетевая политика облачной среды не позволила получить текущую базу Transfermarkt, поэтому обновление **не содержит актуальные цены и фото Transfermarkt для всех игроков**.

Проверки: `npm test`, `npm run test:browser`, `npm run test:website-update`, `npm run test:competitions` из `website/` (для браузерных тестов нужен запущенный Vite). В выпуске 2.2 изменения также включены в Android APK.

## Версия 2.2

Все перечисленные обновления включены в сайт и Android APK 2.2 (versionCode 4). Фотографии футболистов временно отключены: показываются инициалы, сетевых запросов к портретам нет. Эмблемы клубов остаются. Отдельная база изображений будет подключаться позже; описание прежнего поиска портретов выше относится к предыдущей версии.

Настройки → «Удалить текущую карьеру» → подтверждение удаляет только выбранный слот и журнал текущего матча. Другие слоты не затрагиваются. Удаление необратимо без заранее экспортированного JSON; кнопка «Отмена» сохраняет карьеру.
