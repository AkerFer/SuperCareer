# Football Legacy: Career Simulator

Рабочая браузерная и Android-бета 0.2. React + TypeScript + Vite, адаптивный русский интерфейс. Имена игроков и клубов на английском языке. Без регистрации и backend.

## Запуск

Node.js 22+ (проверено на 24), npm.

```sh
cd /workspace/SuperCareer
npm ci
npm run dev -- --port 5173
```

Откройте адрес, напечатанный Vite, в браузере на своей машине. Для production: `npm run build`, затем раздавайте `dist` любым статическим HTTPS-сервером. Данные привязаны к браузеру и origin; перед сменой адреса экспортируйте JSON.

## Возможности

- 96 реальных названий клубов пяти лиг; двойной круг, 380/306 матчей на лигу.
- Создание карьеры: тренер, национальность, клуб, сложность, начальный год.
- 2112 сгенерированных игроков, стартовый состав, запасные, четыре расстановки, три стиля и капитан.
- Матч клуба, тур, пять туров, остаток сезона; таблицы, голы, ассисты, матчи, сухие матчи, карточки, травмы, мораль, усталость.
- Влияние состава, тактики, домашнего преимущества и сложности; воспроизводимый генератор случайности хранится в сохранении.
- Рынок с поиском и фильтрами, предложения цены и зарплаты, покупка, продажа, свободные агенты, продление, ограничения бюджетов и окон. ИИ совершает сделки.
- Смена сезона, история чемпионов и бомбардиров, развитие и старение, истечение контрактов, академия, архив завершивших карьеру.
- Доходы от домашних матчей, выплаты за сезон и места, трансферы, расходы на зарплаты и контракты.
- Три слота, автосохранение, ручное сохранение, экспорт/импорт JSON. Базу можно редактировать через JSON с сохранением ID и связей.

Стартовые клубы соответствуют сезону 2024/25. Игроки стартовой базы используют реальные исторические имена; характеристики, бюджеты и суммы доходов — игровые оценки. Данные и изображения описаны в DATA_SOURCES.md.

## Проверки

```sh
npm test
npm run build
npm run test:browser
```

Браузерный smoke-тест требует Chromium (`/usr/bin/chromium`, либо путь в `CHROMIUM_PATH`) и запущенный Vite на порту 5173. Проверяет создание карьеры, матч, сохранение после перезагрузки, трансфер, таблицу и мобильную ширину. Тесты движка проверяют календарь, связь голов и статистики, атомарность отказов трансфера, бюджет, импорт и 30 сезонов.

## Архитектура и следующий этап

`src/engine.ts` — модель и независимые от React операции симуляции. `src/main.tsx` — интерфейс и localStorage, `src/style.css` — адаптивное оформление. `version: 1` в сохранении предназначена для будущих миграций. Модель работает локально и может использоваться в оболочке Capacitor.

Лига Европы, Лига конференций, UEFA-коэффициенты, аренды, смена клуба, увольнения, тренерский ИИ, детальная экономика и PWA ещё не реализованы. ЛЧ, награды и Android APK доступны. Нижних дивизионов нет, вылеты не симулируются. Капитан хранится как роль, отдельного бонуса капитана пока нет. Награды не подменены случайными результатами.

## Android (Capacitor)

Настоящий Android-проект находится в `android/`, app ID `com.footballlegacy.career`. Android 7.0+ (API 24), target/compile API 36. Игра упакована внутрь APK, обязательного подключения к Интернету нет. Экспорт JSON на Android вызывает системное меню «Поделиться»; импорт использует выбор файла. Сохранения браузера и APK раздельные — переносите карьеру JSON-файлом. Удаление приложения удаляет его локальные сохранения.

Требования: JDK 21, Android SDK с `platforms;android-36`, `build-tools;35.0.0` (по умолчанию AGP), `build-tools;36.0.0`, `platform-tools`. Укажите `ANDROID_HOME` или `sdk.dir` в локальном `android/local.properties`. Локальные SDK, ключи и абсолютные пути не коммитятся.

```sh
npm ci
npm run android:apk
# APK: android/app/build/outputs/apk/debug/app-debug.apk
# Открыть проект в Android Studio:
npm run android:open
```

`android:apk` сначала собирает актуальный web-код, затем синхронизирует его в Android. Для установки на подключённый телефон с USB-отладкой: `adb install -r android/app/build/outputs/apk/debug/app-debug.apk`. Также можно скопировать APK на телефон и открыть, разрешив установку из выбранного источника.

Debug APK предназначен для тестирования. Для Google Play создайте собственный release keystore в Android Studio и используйте Generate Signed Bundle / APK. Ключи подписи не храните в репозитории. APK содержит текущую игровую версию, включая ЛЧ и награды.

- Лига чемпионов: общий этап 36 клубов, стыки, двухматчевый плей-офф, финал, квалификация следующего сезона, история победителей. Это упрощённая игровая адаптация формата, не точное воспроизведение регламента UEFA.
- Ballon d’Or (топ-30), Golden Shoe, The Best, World XI, награды UEFA и каждой лиги. Церемония всех наград с обратным отсчётом, открытием победителей и повтором анимации. Выбор связан со статистикой и трофеями.
- Досье тренера: матчи, победы/ничьи/поражения, голы, процент побед, сезоны, трофеи и персональные награды.
- Кнопка следующего сезона на главной после завершения чемпионатов и ЛЧ; сохранение истории наград и накопленной статистики.
- Анимация переключения вкладок; поддерживается системная настройка уменьшения анимаций.
- Сжатые локальные сохранения `FL2:` с автоматическим чтением старого JSON-формата. Во время живого матча отдельно записывается небольшой журнал с точной минутой, seed и состоянием участвующих игроков; полная карьера сжимается на старте и по завершении матча. Экспорт по-прежнему обычный JSON. Старые карьеры сохраняют результаты, финансы и трансферы; первые исходные игроки получают реальные имена. Прошлые матчи и награды до появления новой системы не выдумываются. При неизвестном возрасте реального игрока используется оценка 26 лет; такие игроки не номинируются на молодёжные награды.

Проверки запускаются теми же командами. Расширенный браузерный тест проходит через перерыв и перезагрузку, доигрывание сезона, вручение двух наград, досье тренера и новый сезон.

### Состав на футбольном поле и замены

Откройте **Клуб → Тактическая доска**. Нажмите футболиста на поле, затем запасного для замены; два касания разных игроков на поле меняют их местами. Можно также сначала выбрать запасного, затем место на поле. Схемы 4-3-3, 4-2-3-1, 4-4-2 и 3-5-2 перестраивают поле, «Автовыбор 11» учитывает амплуа, рейтинг и физическую форму. Неподходящее амплуа снижает силу в симуляции. Выбранному футболисту можно назначить капитанскую повязку или открыть карточку.

Во время прямого эфира нажмите **Состав и замены**: матч встанет на паузу. В перерыве меню доступно без продолжения времени. В заявке до девяти запасных, разрешены пять замен (лимит окон замен в этой версии не моделируется). Вышедший игрок не возвращается; удалённого заменить нельзя. Замены фиксируются в ленте, учитывают минуты, участия, усталость и статистику, сохраняются при перезапуске. Соперник также совершает замены. Перестановки игроков и изменение схемы в матче не обновляют стартовые 11 следующего матча.

APK 0.2 использует тот же app ID и debug-ключ, что и 0.1, с увеличенным versionCode. Устанавливайте как обновление поверх предыдущего приложения; удалять его для установки новой версии не требуется.
